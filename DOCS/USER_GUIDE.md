# Платформа учёта тем ВКР — что сделано и как пользоваться

Документ описывает возможности веб-приложения, различия ролей **ADMIN** и **OPERATOR**, куда нажимать для типовых действий и минимальный порядок запуска для разработчика.

---

## 1. Назначение системы

Сервис на **Next.js 15** и **Appwrite** ведёт справочник **кафедр**, профили пользователей с ролью и привязкой к кафедре, коллекцию **тем ВКР** (`vkr_topics`) с полями: название, кафедра, студент, руководитель, год, примечание. Дубликаты названий в рамках одной кафедры контролируются нормализацией заголовка и уникальным индексом в базе (см. скрипт коллекций).

---

## 2. Роли и что видит пользователь в меню

| Роль        | Главная | Темы ВКР | Кафедры | Операторы | Статистика |
|------------|---------|----------|---------|-----------|------------|
| **ADMIN**  | да      | да       | да      | да        | да         |
| **OPERATOR** | да    | да       | нет     | нет       | нет        |

- **ADMIN** — полный доступ к админ-разделу и ко **всем** темам (с фильтром по кафедре на странице тем).
- **OPERATOR** — только **своя кафедра**: в списке тем и при создании темы сервер подставляет/ограничивает данные по `departmentId` из профиля; список кафедр в интерфейсе для оператора сужен до своей записи.

В шапке отображаются имя пользователя, роль и кнопка **«Выход»**.

---

## 3. Первый запуск и регистрация

### 3.1. Разработчик: окружение и коллекции Appwrite

1. Скопируйте `.env.example` в `.env.local` и заполните переменные (endpoint, project id, database id, id коллекций, `APPWRITE_API_KEY` с правами на Users и Databases).
2. В проекте Appwrite выполните скрипт создания коллекций и индексов (из корня репозитория):

   ```bash
   node scripts/setupCollections.js
   ```

   (Требуются те же идентификаторы и API-ключ, что в `.env`.)

3. Запуск приложения:

   ```bash
   npm install
   npm run dev
   ```

   Откройте `http://localhost:3000`.

### 3.2. Первый пользователь = единственная открытая регистрация

- Страница **`/register`** доступна **только пока в системе ещё нет ни одного администратора**.
- После успешной регистрации создаётся аккаунт **администратора**; дальнейшие заходы на `/register` перенаправляют на **`/login`**.
- Новых пользователей (операторов) администратор создаёт вручную в разделе **«Операторы»** (см. ниже).

### 3.3. Вход

- Откройте **`/login`**, введите email и пароль.
- Без сессии защищённые страницы перенаправляют на вход.

## 4. Администратор (ADMIN): порядок работы

Рекомендуемый порядок после первого входа:

1. **Кафедры** (`/admin/departments`)  
   - Блок **«Новая кафедра»**: поля **Название** (обязательно), **Код** (по желанию) → кнопка **«Добавить»**.  
   - В списке можно **редактировать** и **удалять** записи (элементы управления в строке списка).

2. **Операторы** (`/admin/operators`)  
   - Форма **«Новый оператор»**: **ФИО**, **Email**, **Пароль** (не менее 8 символов), **Кафедра** (выбор из справочника) → отправка формы создаёт пользователя Appwrite и профиль с ролью `OPERATOR` и выбранной кафедрой.  
   - Ниже — список созданных операторов.

3. **Темы ВКР** (`/topics`)  
   - **Фильтр по кафедре** (выпадающий список): **«Все кафедры»** или конкретная кафедра — влияет на **отображаемый список** тем.  
   - Кнопка **«+ Добавить тему»** открывает **модальное окно** создания темы.  
   - Если перед открытием выбрана кафедра в фильтре, в форме создания поле **«Кафедра»** может быть **предзаполнено** этим значением (его всё равно можно сменить).  
   - В модалке: **Название темы** (обязательно), **Кафедра** (обязательно при создании), опционально студент, руководитель, год, примечание → **«Добавить тему»**.  
   - У строки темы: **«Изменить»** — та же модалка в режиме редактирования; **«Удалить»** — с подтверждением.  
   - При вводе названия может появиться **предупреждение о дубликате** по нормализованной формулировке в пределах выбранной/текущей кафедры (информационно; окончательная проверка — на сервере).

4. **Статистика** (`/admin/stats`)  
   - Сводные цифры по темам (в т.ч. по кафедрам), операторам, добавлениям по месяцам (на момент реализации страницы).

### Закрытие модалки темы

Кнопка **крестик**, кнопка **«Отмена»**, клик по **затемнённому фону**, клавиша **Escape**.

---

## 5. Оператор (OPERATOR)

- В меню доступны **«Главная»** и **«Темы ВКР»**.  
- На странице тем в подзаголовке указана **своя кафедра**; фильтра по всем кафедрам нет.  
- **«+ Добавить тему»** — модалка: кафедра в форме **не выбирается** — тема создаётся **автоматически** для кафедры из профиля оператора.  
- **«Изменить»** / **«Удалить»** — только для тем своей кафедры (остальные темы в списке не попадают).

---

## 6. Главная страница

Краткая информационная зона после входа (роль и подсказки по разделам в зависимости от прав).

## 7. Технические заметки (для сопровождения)

- Запросы к собственным API (`/api/...`) идут через обёртку **`appwriteApiFetch`**: передаются учётные данные сессии Appwrite (в т.ч. режим с `localStorage` / fallback-cookies), чтобы серверные маршруты видели того же пользователя, что и клиент SDK.  
- **GET `/api/topics`**: оператор всегда получает темы только своей кафедры; администратор может запрашивать все или с `?departmentId=...`.  
- **GET `/api/departments`**: администратор — полный список; оператор — только документ(ы) своей кафедры.

Подробности схемы коллекций и индексов — в `scripts/setupCollections.js` и комментариях в коде API.

## 8. Краткая шпаргалка «куда нажать»

| Действие                         | Кто        | Куда |
|----------------------------------|------------|------|
| Первый вход в систему            | будущий ADMIN | `/register` (один раз) |
| Обычный вход                     | все        | `/login` |
| Создать кафедру                  | ADMIN      | Кафедры → форма «Новая кафедра» → Добавить |
| Создать оператора                | ADMIN      | Операторы → заполнить форму → отправка |
| Добавить тему                    | ADMIN / OPERATOR | Темы ВКР → **+ Добавить тему** → модалка → Добавить тему |
| Изменить / удалить тему          | ADMIN / OPERATOR | Темы ВКР → **Изменить** / **Удалить** у строки |
| Отфильтровать темы по кафедре    | только ADMIN | Темы ВКР → «Фильтр по кафедре» |
| Посмотреть агрегированную статистику | ADMIN   | Статистика |

Если нужно расширить этот файл (скриншоты, схема БД, деплой), можно добавить отдельные документы в папку `DOCS/`.
